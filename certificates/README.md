# Certificates

The 10 Claude / Anthropic Academy certificate PDFs shown in the site's
**Certifications** section. Each certificate name on the page links here and
opens the PDF in a popup (with an "open in new tab" fallback for mobile).

Filenames must stay in sync with the `openCert(...)` calls in `index.html`:

| File | Certificate |
|---|---|
| `ai-fluency-framework-foundations.pdf` | AI Fluency: Framework & Foundations |
| `ai-fluency-ai-capabilities-limitations.pdf` | AI Fluency: Capabilities & Limitations |
| `claude-101.pdf` | Claude 101 |
| `claude-platform-101.pdf` | Claude Platform 101 |
| `claude-with-anthropic-API.pdf` | Claude with the Anthropic API |
| `claude-code-101.pdf` | Claude Code 101 |
| `claude-code-in-action.pdf` | Claude Code in Action |
| `introduction-to-MCP.pdf` | Introduction to Model Context Protocol |
| `MCP-advanced-topics.pdf` | MCP: Advanced Topics |
| `introduction-to-agent-skills.pdf` | Introduction to Agent Skills |

To replace one, keep the same filename.
